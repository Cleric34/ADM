Guru Drona has cast the 7-ring Chakravyuha. Arjuna is drawn away. Abhimanyu alone penetrates the wheel, knowing the entry secrets, but none to escape.

  4. Jayadratha Lock: Outer gate seals upon entering Ring 7. Discover hidden exit gates 🚪 in fog!
  5. Win: Breach the golden Core (★), then escape through the outermost Exit Gate.
